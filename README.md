# 术中植入路径动画时间轴

React + Babylon.js 的术中植入路径动画时间轴系统:为植入器械、导针和相机各建一条轨道,在统一时钟下编排进钉过程。

## 运行

```bash
npm install
npm run dev    # http://localhost:5173
npm run build  # 生产构建
```

## 功能对照

| 需求 | 实现 |
|---|---|
| 1. 三条轨道打关键帧 | 器械/导针/相机三条轨,记录位置+朝向;轨道上的 ● 按钮在播放头处记录当前 3D 姿态(工具栏「操作手柄」可先在场景里拖动物体) |
| 2. 拖动播放头预览 | 拖标尺任意位置即跳转到该时刻,器械沿骨面滑入钉道过程逐帧可见 |
| 3. 缓动曲线 | 双击关键帧(或选中后点「调曲线」)打开贝塞尔曲线编辑器,拖控制点或选预设;进钉道前「缓出」减速、进入后「缓入」加速 |
| 4. 编组整拖 | 勾选多条轨道后点「编组」;组条整体拖动改起止时间,拖右缘改时长,组内相对节奏不变(子节点存组内本地时间,组做 start+scale 映射) |
| 5. 嵌套组 | 组可嵌组(默认演示里「导针动作」嵌在「器械+相机」内);时间映射沿祖先链复合,嵌套拖动与单独回放采样结果一致 |
| 6. 改时长自动重排 | 「涟漪重排」开启时,移动关键帧/改段时长,该轨后续关键帧按位移整体平移,不堆叠 |
| 7. 多轨同步 | 所有轨道从同一播放头时钟采样,拖动时器械与相机位置同时更新 |
| 8. 相机路径点 | 相机轨道关键帧 = 路径点(位置+观察目标);关「相机轨道」自由环绕找角度,开「相机轨道」后 ● 记录路径点,默认演示自带绕钉道口一圈 |
| 9. 持久化 | 「保存」写入 localStorage,下次打开自动恢复(轨道/编组/曲线都在);「导出/导入」为 JSON 文件 |

## 结构

```
src/
  layout.ts            场景几何常量(骨骼、钉道入口/末端),演示关键帧与 3D 场景共用
  timeline/
    types.ts           轨道/关键帧/组的数据模型(组可嵌套,start+scale 时间映射)
    easing.ts          cubic-bezier 求解(牛顿迭代+二分兜底)与预设
    model.ts           采样、关键帧操作、涟漪重排、编组/解组、序列化
    math3d.ts          四元数/欧拉角换算(Babylon YXZ 约定)
    store.tsx          React 状态、播放循环、localStorage 持久化
    defaultDoc 内置于 model.ts(createDefaultDoc 演示数据)
  scene/createScene.ts Babylon 场景:骨骼、钉道、器械、导针、相机、路径辅助线、操作手柄
  components/          Viewport / Toolbar / Timeline / CurveEditor
```

## 关键设计

- **时间映射**:每个节点(轨道或组)存 `start` + `scale`,全局时间沿祖先链逐层反映射为本地时间再采样,因此编组、嵌套、整组拉伸都只是改映射,组内相对节奏天然不变。
- **单一时钟**:播放头时间是唯一状态源,所有轨道每帧按它采样,多轨同步不需要额外对齐逻辑。
- **相机轨道的 rotation 字段**复用为观察目标点(lookAt),关键帧即路径点。
