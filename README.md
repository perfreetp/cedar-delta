# 婚礼迎宾区 · 立体字排版工具

浏览器内完成从字体导入到立体字成型的全部编辑。技术栈：TypeScript + React + three.js + opentype.js。

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 类型检查 + 产物构建
npx tsx scripts/smoke.ts   # 几何/排布逻辑冒烟测试
```

## 四个模块

1. **字体导入台** — 读取本地 .ttf/.otf/.woff（opentype.js 纯本地解析），列出可用字形，点击预览轮廓，双击或按钮加入排布。
2. **单字立体化** — 字形挤出成三维字块：挤出厚度、侧边斜切（倒角宽度/厚度/分段，滑块拖动）、前脸内凹浮雕（缩放+深度）。轮廓在解析时自动清理：去重点、去共线、去尖刺、自交检测、孔洞按包含深度归属外轮廓并统一环绕方向，保证三角化正确。
3. **排布台** — 字块沿直线或圆弧路径依次摆放：字间距、整体弧度、凸向翻转；每块朝向沿路径切线（弧面法线随曲率逐块重算）。重叠判定用弦距（弧排时弦距 < 弧距，直排不重叠弧排可能重叠），检测到重叠给出红色提示线与一键「吸附对齐」。
4. **成品台** — 接缝检查（相邻间隙、重叠计数），导出 GLB（保留结构，供分享）或 STL（合并单体，供 3D 打印）。

## 关键设计

- **整体回退**：快照式不可变状态 + 历史栈，Ctrl+Z / Ctrl+Y；滑块拖动合并为单条历史（拖动开始记快照、松手提交）。
- **性能**：几何体按「字形 + 挤出参数」缓存（LRU 256 条），同字形字块共享几何；视口按 state 差量同步网格，拖动滑块只更新 transform，几百字块不重建几何。
- **内凹浮雕**：以缩放轮廓的薄壳嵌片贴于前脸（polygonOffset 视觉内凹），避免 CSG 开销；如需真实切削可后续接 three-bvh-csg。
