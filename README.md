# 应急演练场地布点工具

基于 **Vue 3 + Three.js + Vite** 的应急演练场地三维布点与布置图导出工具。

## 启动

```bash
npm install
npm run dev
```

浏览器打开终端提示的地址（开发服务器固定尝试 `http://localhost:5188`，端口占用时 Vite 会自动顺延）。

生产构建：

```bash
npm run build
npm run preview
```

## 已实现能力

- 长方形场地长度、宽度、主通道宽度与走向设置。
- 帐篷、集结点、物资堆放区、警戒桩四类物件，每类 5 个数量档位。
- 确定性自动排布：同类物件保留净距，不压主通道，并自动划分功能区。
- 物件可直接在三维画布中拖动；已拖动物件在重新生成时受保护保留。
- 拖到通道、边界或与其他物件冲突时，自动搜索并弹回最近合法空位。
- 每个物件可单独旋转、90° 快速转向和等比例尺寸调整。
- 手动移动 / 旋转 / 缩放后，物件旁显示琥珀色“调”记号，并进入右侧手动清单。
- 右侧清单点击高亮对应物件，可单项恢复自动位置，也可全部恢复自动布局。
- 种子快照保存在浏览器 `localStorage`；输入同一种子并点击“按种子复现完整布局”，可恢复该次参数、物件变换和手动状态。
- 一键生成 SVG 场地布置图，包含：
  - 场地总尺寸；
  - 主通道宽度标注；
  - 同类物件净距标注与间距表；
  - 功能分区、编号、图例、指北针；
  - 手动调整清单和现场签字栏；
  - PNG / SVG 下载与打印。

## 关键目录

```text
src/
  App.vue                  # 主界面、状态与交互编排
  components/PlanDialog.vue# 布置图预览与导出
  layout/engine.js         # 参数、约束、自动排布、最近空位搜索
  layout/planSvg.js        # SVG 布置图生成
  layout/seedStore.js      # 种子完整布局快照
  three/SceneManager.js    # Three.js 场景、模型、拖拽、高亮和回弹
```

> 说明：种子完整快照保存在当前浏览器本地；同一浏览器配置下可跨刷新复现。
