# 偶头面容雕刻台 · Symmetry Sculpt Studio

一个使用 **TypeScript + React + Three.js** 实现的偶头基础网格雕刻应用。工作区由四个连续模块组成：

1. **导入基础网格**：自动加载内置 X 对称偶头，也可导入 `.obj` / `.glb` / `.gltf`。
2. **笔刷塑形**：抓取、隆起、压平、平滑；直径和强度均为三档；悬停显示作用范围圆环。
3. **X 轴对称**：镜像中心、位移向量和压平平面；可单独开关 `+X` / `−X` 一侧；轴线顶点只处理一次并锁定 `X = 0`。
4. **笔划管理与导出**：记录每笔的逐顶点 `from/to/delta`，支持撤销、重做、点击条目回放、定时逐条回放，并导出当前 OBJ / GLB 网格。

## 运行

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出的地址（默认 `http://127.0.0.1:5173`）。

生产构建：

```bash
npm run build
npm run preview
```

核心算法测试：

```bash
npm test
```

## 操作

- **左键拖动**：使用当前笔刷雕刻。
- **右键拖动**：旋转视角。
- **滚轮**：缩放。
- **中键拖动**：平移。
- `G` / `R` / `F` / `S`：切换抓取 / 隆起 / 压平 / 平滑。
- `Ctrl/Cmd + Z`：撤销。
- `Ctrl/Cmd + Shift + Z` 或 `Ctrl + Y`：重做。

## 关键实现

### 网格与命中

- 导入的非焊接网格会被转为位置数据、归一化尺寸，并通过 `mergeVertices` 焊接重复顶点，然后建立索引和一邻接关系。
- 表面命中使用 Three.js `Raycaster` 和网格包围球宽相检测。
- 笔刷候选顶点直接在 `Float32Array` 上做平方距离查询；对几千顶点的偶头网格，每帧全量扫描仍是亚毫秒到数毫秒级，避免了复杂 BVH 的维护成本。

### 对称合并

对称开启时，对每个顶点按当前 `x` 符号分区：

- `+X` 顶点只分配给正侧笔刷中心；
- `−X` 顶点只分配给镜像中心；
- `|x| <= axisEpsilon` 的轴线顶点只进入候选集一次。

抓取位移在镜像侧翻转向量的 X 分量；压平平面的点和法线同样镜像 X。这样原始笔刷和镜像笔刷不会顺序叠加，也不会重复处理轴线顶点。

### 精确撤销 / 重做

每一笔在落笔时复制位置缓冲，提交时为受影响顶点保存：

- `indices`
- `from`：落笔前的精确坐标
- `to`：收笔后的精确坐标
- `delta = to - from`：逐顶点位移数据

撤销直接恢复 `from`，重做直接恢复 `to`，因此连续笔划在同一顶点叠加后，也能精确回到上一笔之前，而不是依赖浮点数反向累加。

### 加权平滑

`topology.ts` 从索引三角形建立一邻接边以及每条边对应的对角顶点。平滑笔刷使用动态 **Cotangent 边权**（负权裁剪为 0，退化时回退到反距离权）计算邻接顶点的加权中心，再按笔刷衰减和强度混合。单次笔戳先计算全部位移、后统一写入，避免顶点遍历顺序造成的偏差和局部塌陷。

## 目录

```text
src/
  App.tsx                    # React 工作台与模块布局
  components/                # 笔刷、对称、笔划列表面板
  sculpt/
    SculptEngine.ts          # Three.js 场景、指针、圆环、渲染循环
    kernel.ts                # 无框架依赖的笔刷/对称变形核心
    history.ts               # 笔划记录、撤销重做、回放
    topology.ts              # 邻接边与 Cotangent 权所需拓扑
    createDollHead.ts        # 内置偶头基础网格
    meshIO.ts                # OBJ/GLB/GLTF 导入与 OBJ/GLB 导出
    core.test.ts             # 对称、历史、平滑核心测试
```
