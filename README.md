# 激流赛道河床地形编辑器

面向赛道设计师的浏览器端三维水道地形塑造工具。基于 **TypeScript + React + three.js + three-mesh-bvh**,以高度场网格承载河床,覆盖雕刻、坡度剖面、闸门布置与赛道导出四个模块。

## 快速开始

```bash
npm install
npm run dev          # 启动开发服务器(默认 http://127.0.0.1:5173)
npm run build        # 类型检查 + 生产构建
npm run test:logic   # 纯逻辑冒烟测试(中心线/剖面/台阶/闸门/笔刷/历史)
```

## 功能模块

### 1. 地形雕刻
- 129×129(16 641 顶点)高度场网格承载河床
- 四种笔刷:**抬升 / 下压 / 平滑 / 拉平**,半径(2–30 m)与强度(5–100%)可调
- 抬升/下压实时重算法线;**three-mesh-bvh** 加速鼠标射线拾取,雕刻后以 `boundsTree.refit()` 增量更新而非重建整树
- **对称笔刷**:沿赛道中心线镜像触点,同时雕刻两岸
- 拉平以落笔处高程为目标,向目标高程收敛

### 2. 坡度剖面
- 沿河道中心线(Catmull-Rom 样条 + 弧长参数化)自动生成纵坡剖面,底部 SVG 图表随编辑联动重绘
- 可插入**落差台阶**形成跌水段;台阶前后坡面按设定角度自动过渡,过渡段长度 = 落差 / tan(角度),smoothstep 缓入缓出
- 相邻台阶过渡段重叠时给出校验提示
- 中心线控制点拖拽调整弯道曲率,**河床宽度随曲率自适应收窄**(最窄为基础宽度 45%)

### 3. 闸门布置
- 鼠标沿地形表面移动时,幽灵门实时预览
- 门杆自动**吸附到落点等高线切线方向**(与地形梯度垂直;近水平处回退中心线切向)
- 两端立柱落到地面并记录**入水高度**(两立柱地面均值)
- 拖动闸门时门杆重新吸附、立柱重新落地,**下游坡度剖面联动重算**
- 红/绿门规则、门宽可调、Delete 删除

### 4. 赛道导出
- 导出自包含 `.whtrack.json`:网格规格、中心线控制点、台阶、闸门、全部河床高程
- 支持重新导入继续编辑(导入清空历史并整体载入)

## 历史记录

雕刻、台阶插入/修改、闸门放置/移动/改宽、中心线控制点移动均在编辑开始前压入快照。
快照统一包含 `高度场 + 控制点 + 台阶 + 闸门` 四份数据,因此撤销/重做后地形与闸门位置始终保持一致(闸门按快照坐标原样恢复)。支持 `Ctrl+Z` 撤销、`Ctrl+Shift+Z` / `Ctrl+Y` 重做,上限 60 步。

## 架构

```
src/
├─ lib/                  纯逻辑层(不依赖 React / WebGL,可独立测试)
│  ├─ centerline.ts      Catmull-Rom 样条、弧长参数化、曲率、自适应河宽、空间哈希最近投影
│  ├─ terrain.ts         高度场构建、四种笔刷、双线性采样、顶点配色
│  ├─ profile.ts         纵坡剖面、台阶角度过渡、下游坡度、重叠校验
│  ├─ gates.ts           等高线切线吸附、立柱落地、入水高度、重新落地
│  ├─ history.ts         统一快照的撤销/重做栈
│  ├─ serializer.ts      赛道文件导出/导入
│  ├─ bvh.ts             three-mesh-bvh 原型挂载
│  ├─ noise.ts           确定性值噪声(可复现河床起伏)
│  ├─ constants.ts       网格/河床/笔刷全局参数
│  └─ types.ts           共享类型
├─ three/
│  ├─ EditorEngine.ts            场景基类:渲染、地形网格、BVH、中心线/闸门资源
│  └─ EditorEngineInteractive.ts 交互子类:指针编辑、拖拽、台阶、历史恢复
├─ components/           React UI(顶栏、四模块面板、SVG 剖面图、视口)
├─ store.ts              zustand 全局状态(高度场留在引擎中,不进 React)
└─ engineRegistry.ts     React ↔ 引擎实例桥接
```

### 性能策略
- **拾取走 BVH**:射线与 32k 三角形求交由 `three-mesh-bvh` 加速
- **雕刻增量更新**:仅写回受影响顶点、重算法线、`refit()` BVH,不重建整树
- **中心线拖拽合帧**:`requestAnimationFrame` 合并高频重建,拖拽期间跳过 BVH(走 Y 平面求交),松手再建
- **空间哈希**:`buildHeights` 对 16k 顶点做中心线最近投影时用网格哈希粗查,避免 O(n·m) 全扫描
- React 状态只存轻量数据(控制点/台阶/闸门/UI),16k 高程的 Float32Array 由引擎持有,避免每帧触发 React 渲染
