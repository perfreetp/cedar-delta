# 街景方案生成器

按参数生成动画街景的方案工具。Svelte 4 + Babylon.js + Vite。

## 运行

```bash
npm install
npm run dev    # http://localhost:5173
npm run build  # 产物在 dist/
```

## 功能

1. **参数滑块** — 左侧调节街区长度 / 层高 / 楼栋密度,画布实时重新排布
2. **种子确定性** — 每栋楼的窗户网格、屋顶样式由 `hash(种子, 楼id)` 决定,同种子重新生成结果完全一致
3. **点选编辑** — 点击楼体,在左侧面板改高度、屋顶、窗户行列,该楼记为「手改」
4. **手改保留** — 再调街区长度等参数时,手改过的楼保持原样,其余楼按种子重新生成
5. **字段级依赖** — 窗户行数 = 高度 ÷ 层高,随层高联动;手动改过窗户排布的楼不被覆盖
6. **路灯/行道树** — 按密度自动沿街摆放;拖动路灯可沿街调整它与路对面的对齐位置(记为手改)
7. **种子重置** — 顶部输入种子编号,一键回到该种子初始街景并清空全部手改记录
8. **方案存取** — 当前参数 + 手改项可命名保存到 localStorage,随时载入;当前工作状态也自动持久化,刷新页面后还原
9. **环绕视角** — ArcRotateCamera,拖动旋转、滚轮缩放,任意角度观察楼群与街道

## 结构

```
src/
  App.svelte            顶栏(种子/方案)+ 左侧参数与楼栋编辑面板
  lib/
    rng.js              mulberry32 + 字符串哈希,确定性随机源
    generate.js         纯函数 computeScene(params, overrides) → 街景数据
    store.js            Svelte stores、手改覆盖、localStorage 持久化与方案管理
    StreetScene.svelte  Babylon 场景:建楼/屋顶/窗户实例化/路灯拖拽/车辆与云动画
```

关键设计:街景是 `(params, overrides)` 的纯函数。手改按**字段级**覆盖
(`buildings[id] = {height?, roof?, windows?}`),重新生成时只有未覆盖的字段
重新按种子计算,因此调参数不会冲掉手改内容。楼 id 由街道侧别 + 槽位索引
构成,长度变化时前排楼的 id 稳定,手改记录随之保留。
